# 🧭 Start here

**For:** complete beginners who want a solid base before choosing a specialty.
**Time:** roughly 2 to 3 months at a few hours a week.

Security is built on understanding how systems normally work. This path gets you comfortable with Linux, networks and the web, then lets you practice legally.

## 1. Get comfortable with Linux

- Play [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) from level 0. Each level teaches one command-line skill over SSH.
- Work through the first dojos of [pwn.college](https://pwn.college/), beginning with "Start Here".

**You're ready to move on when** you can navigate the filesystem, read man pages, use pipes and redirection, and understand file permissions without looking them up.

## 2. Understand networks

- Install [Wireshark](https://www.wireshark.org/) and capture your own traffic while you browse. Find a DNS lookup, a TCP handshake and an HTTP request.
- Scan your own machine or a home lab VM with [Nmap](https://nmap.org/) and compare the results with what you know is running.

## 3. Learn how the web works, and breaks

- Start the free [Web Security Academy](https://portswigger.net/web-security) with the SQL injection and cross-site scripting topics.
- Read the [OWASP Top 10](https://owasp.org/www-project-top-ten/) to see the most common risk categories.
- Run [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) locally and solve the one-star challenges.

## 4. Play your first CTFs

- Practice on [picoCTF](https://picoctf.org/), designed for beginners.
- Try the free rooms on [TryHackMe](https://tryhackme.com/) or Starting Point on [Hack The Box](https://www.hackthebox.com/).
- Find a beginner-friendly event on [CTFtime](https://ctftime.org/) and read other teams' writeups afterwards. Writeups are one of the fastest ways to learn.

## 5. Keep a reference close

- [CyberChef](https://gchq.github.io/CyberChef/) for decoding and transforming data.
- [CTF Wiki](https://ctf-wiki.org/) for explanations of each CTF category.

## Where next?

Pick the path that interests you most: [Web](web.md), [Blue team](blue-team.md), [Networks and AD](network-ad.md), [Reverse engineering](reverse-engineering.md) or [Cloud and DevSecOps](cloud-devsecops.md).
