# Security policy

This repository is a list of links, so the main risk is a listed project being compromised, taken over or replaced with something malicious.

If you notice that:

- a listed GitHub project or website now distributes malware,
- a project was transferred to a suspicious owner, or
- a domain has expired and been taken over,

please report it privately through [Security advisories](https://github.com/Ethos6/Hacking/security/advisories/new). We aim to respond within 3 working days and remove or replace the entry immediately when confirmed.

For vulnerabilities in a listed project itself, contact that project's maintainers directly.
